# Protocol amendment 001: Java 21

Date: 2026-08-13  
Applied before any formal ranking or held-out qrel access.

## Original specification

The initial plan paired Pyserini 2.3.0 with Java 17.

## Observed incompatibility

The first development-only SciFact indexing attempt failed before retrieval. The
Lucene classes shipped with Pyserini 2.3.0 use class-file version 65, while Java 17
supports at most class-file version 61. The JVM raised
`UnsupportedClassVersionError`.

Pyserini's official installation documentation specifies Python 3.12 and Java 21:
<https://github.com/castorini/pyserini#installation>. Its historical note records the
project's migration to JDK 21 in April 2024.

## Resolution

Keep the planned Pyserini 2.3.0 and Lucene scoring implementation, and amend the Java
runtime from 17 to 21. This resolves an execution prerequisite without changing the
retriever version, analyzer, BM25 parameters, queries, documents, or evaluation.

The runner now locates and verifies Java 21 before importing Pyserini. It fails closed
if Java 21 is unavailable. The failed Java 17 attempt remains documented here rather
than being omitted from the research record.
