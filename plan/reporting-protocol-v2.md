# Seven-dataset reporting protocol

## Evaluation scope

The report treats SciFact, NFCorpus, TREC-COVID, FiQA, ArguAna,
Touché-2020, and SCIDOCS as seven evaluation datasets. Every dataset receives
equal weight in macro estimates, with dataset-level results reported separately.

## Comparisons and outcomes

The primary comparisons are DESA versus Original and DESA versus
Shared expansion. The seven-dataset report includes nDCG@10, Recall@20, dense
and sparse replay stopping depths.

HyDE, MuGI, and Query2doc are summarized over the same seven datasets.

## Provenance

This file records the pooled reporting scope. The original experiment protocol
and frozen result artifacts remain unchanged.
